This project is an interactive tool developed to facilitate conversion between different numerical bases. It was created with a focus on User Experience (UX), utilizing modern visual effects and structured JavaScript logic.

---

## 📘 Overview

**Objective:**
To provide a fast and intuitive interface for students and developers to perform conversions between Decimal, Binary, Octal, and Hexadecimal, as well as supporting character encoding (ASCII) to binary.

### 🎯 Key Features
* **Decimal ⬌ Binary:** Direct conversion of decimal numbers and encoding of text/letters into their respective binary values.
* **Binary ⬌ Octal:** Grouping logic of bits (octets) for precise conversion.
* **Binary ⬌ Hexadecimal:** Conversion based on nibbles (4 bits) with support for A-F characters.
* **Intelligent Interface:** A "visual focus" system that uses dynamic opacity to highlight the specific converter the user is currently interacting with.

---

## 🛠️ Technical Details

The project demonstrates proficiency in DOM manipulation and algorithmic logic:
* **Conversion Algorithms:** Implementation of `parseInt()` and `toString(base)` combined with `padStart` to ensure correct bit alignment.
* **String Manipulation:** Logic to handle empty spaces and special character separation during conversion.
* **Visual Effects:** Use of SVG filters (Gooey effect) and CSS animations to create a dynamic and modern background.

### Technologies Used
* **JavaScript (ES6+):** Conversion logic and event handling.
* **HTML5 & CSS3:** Semantic structure and advanced styling (Gradients, Glassmorphism).
* **SVG Filters:** For the fluid background animation effect.
